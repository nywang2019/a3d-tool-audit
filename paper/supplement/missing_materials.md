# Missing materials and blocking issues

## Required before Applied Intelligence submission

- Final author list, order, affiliations, emails, and ORCID identifiers.
- Co-author consent.
- Funding statement.
- Competing-interest statement.
- Human-subjects response; likely `N/A`, but must be confirmed.
- Prior-publication response; likely `No`, but must be confirmed.
- Stable code repository URL and archival DOI.
- Public reviewer-accessible benchmark URL.
- Final release license.
- Hosting and maintenance owner/plan.
- Dataset version, checksum manifest, and retained-data policy.
- Reproducibility checklist.
- Final Springer Nature PDF compiled from the assembled package.
- Source and supplementary ZIPs within the journal upload limits.
